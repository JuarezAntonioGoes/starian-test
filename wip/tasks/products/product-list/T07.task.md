## Descrição

Escrever os testes unitários do `ProductListComponent` cobrindo todos os TACs relacionados ao template: renderização da tabela, estados de loading/erro/vazio e navegação.

## Subtarefas

- [ ] 1. Configurar `TestBed` com `ProductListComponent` standalone, `ProductService` mockado e `RouterTestingModule`
- [ ] 2. Testar: exibe `mat-spinner` quando `loading = true`
- [ ] 3. Testar: renderiza N linhas na tabela para N produtos
- [ ] 4. Testar: cada linha exibe imagem, título, categoria, preço e avaliação
- [ ] 5. Testar: cada linha exibe botões "Editar" e "Excluir" com `aria-label`
- [ ] 6. Testar: exibe bloco de erro quando `error !== null`
- [ ] 7. Testar: clique em "Tentar novamente" chama `loadProducts()`
- [ ] 8. Testar: exibe "Nenhum produto encontrado" quando `products = []`, `loading = false`, `error = null`
- [ ] 9. Testar: clique em "Novo Produto" navega para `/products/new`
- [ ] 10. Testar: clique em "Editar" navega para `/products/:id/edit`
