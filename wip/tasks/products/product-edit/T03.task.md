## Descrição

Estender o `ProductFormComponent` existente para suportar modo edição via `@Input() initialData?: Product`. Quando fornecido, pré-preenche o formulário e usa `updateProduct()` no submit.

## Subtarefas

- [ ] 2. No `ngOnInit`, se `initialData` fornecido: preencher o formulário com os valores
