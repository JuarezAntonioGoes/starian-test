## Descrição

Criar o `ProductEditComponent` standalone que lê o `id` da rota, carrega o produto via `getProduct()` e delega a renderização para `ProductFormComponent` com `[initialData]`.

## Contexto

**Tech spec referência:** seção "Componentes — ProductEditComponent"
**ACs cobertos:** TAC03, TAC04, TAC05

## Critérios de Conclusão (DoD)

- [ ] Código implementado conforme a tech spec

## Subtarefas

- [ ] 1. Criar `src/app/features/products/product-edit/product-edit.component.ts`
  - Signals: `product`, `loadingProduct`, `loadError`
  - `ngOnInit`: lê `id` da `ActivatedRoute`, valida (NaN → loadError imediato), chama `getProduct(id)`
  - Em sucesso: `product.set(data)`
  - Em erro: `loadError.set(mensagem)`
- [ ] 2. Criar `product-edit.component.html` com:
  - `@if loadingProduct()` → `mat-spinner`
  - `@else if loadError()` → mensagem de erro + botão "Voltar"
  - `@else` → `<app-product-form [initialData]="product()" />`
