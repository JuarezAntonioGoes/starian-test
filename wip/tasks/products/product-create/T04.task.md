## Descrição

Criar o `ProductFormComponent` standalone com formulário reativo, toolbar, campos validados, estados de saving/erro e navegação. Deve suportar modo criação (sem `initialData`) e ser extensível para edição.

**Tech spec referência:** seção "Componentes" e "Fluxo de Dados"

## Subtarefas

- [ ] 1. Criar `src/app/features/products/product-form/product-form.component.ts`
  - `@Input() initialData?: Product`
  - Signals: `saving`, `saveError`
  - `FormGroup` com campos: `title`, `price`, `description`, `category`, `image`
  - `ngOnInit`: pré-preencher se `initialData` fornecido
  - `onSubmit()`: chama `createProduct()` ou `updateProduct()` conforme modo
  - `onCancel()`: navega para `/products`
- [ ] 2. Criar `product-form.component.html` com:
  - `mat-toolbar` com título dinâmico e botão voltar
  - `mat-form-field` para cada campo com `mat-error` para validações
  - Botão "Salvar" com `[disabled]` quando inválido ou `saving`
  - `mat-spinner` inline no botão durante saving
  - Bloco de `saveError` abaixo do formulário
- [ ] 3. Criar `product-form.component.scss`
